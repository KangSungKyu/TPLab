- [결정됨] 검토했으나 채택하지 않은 대안: 가이드는 현재 AGENTS에 짧은 규칙을 두고 상세만 가이드로 연결하는 안, 결정 기록은 별도 결정 문서 없이 현행 백로그/회고를 유지하는 안. 이는 원안 선택지의 기록이며 4분류 채택으로 AGENTS 이관을 승인하거나 새 결정 파일 생성을 요구하지 않는다. 근거: 사용자 2026-10-13 일괄 승인(D-H9).
