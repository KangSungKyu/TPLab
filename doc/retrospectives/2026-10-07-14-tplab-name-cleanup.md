- 요청: 폴더 이동 이후 남은 이전 이름을 가급적 제거한다.
- 기준: main `6828547da628d70f49e374bde138041de9b4c476`; 별도 `codex/tplab-name-cleanup` 생성. 기존 dirty 파일과 사용자 Build Settings 변경을 분리한다.

- 기록 보존: 과거 실행 로그·JSON·해시·회고의 이전 이름은 원문을 보존한다. 현재 도구 예제와 섞지 않도록 지침과 이름 안내를 정리했다.
